# main.sh の挙動の確認（証拠）

入力: `input.txt`（先頭が半角空白・タブ・空白のみの行を含む）、`input_ws.txt`（全角空白を含む）、`empty.txt`（空）。すべて `sh main.sh <入力> <パターン> <接頭辞>` を作業ツリーの直下で実行。

1. 引数が足りないとき
   - `sh main.sh` / `sh main.sh input.txt` / `sh main.sh input.txt ERROR` → 使い方を標準エラーに出し、終了コード 1。出力ファイルは作られない。
2. 入力ファイルが無いとき
   - `sh main.sh wip/research/nofile.txt ERROR wip/research/out_missing` → 「エラー: 入力ファイルが見つかりません: …」を標準エラーに出し、終了コード 1。出力は作られない。
   - 入力にディレクトリを渡しても同じく終了コード 1。
3. 絞り込みパターン
   - 空文字 `""` → 全行が残る（終了コード 0）。
   - `ERROR` → 含む行だけ残る（終了コード 0）。
   - `C:\path` → 文字どおりに一致（`\` は素の文字）。
   - `*` → 文字どおりに一致（glob として展開されない）。
4. 一致する行が無いとき（`ZZZ`）→ 終了コード 0。`out_none.txt` は 0 バイトで作られる。入力が空のときも同じ（終了コード 0、0 バイト）。
5. 整形
   - 行頭の半角空白とタブは除かれ、番号が 1 から振られる（`  ERROR one` → `1. ERROR one`、`\tERROR two` → `2. ERROR two`）。
   - 全角空白（U+3000）は除かれない（`1. 　　ERROR zen`）。`awk` の `[ \t]` は ASCII の空白とタブだけを扱うため。
   - 空行は番号付きで `7. ` として残る（パターンが空のとき）。
6. 出力ファイルが既にあるとき → 上書きされる（`old` が消え、新しい内容だけになる）。追記はしない。
7. README との突き合わせ（「完成の確認」）
   - 引数不足 → 使い方を表示して終了（一致）。
   - 入力ファイル無し → エラーで終了（一致。終了コード 1）。
   - 一致行無し → 空の出力ファイルを作って正常終了（一致。終了コード 0、0 バイト）。
   - 補足: README の「整形の中身は自由」に対し、全角空白は除かれないことだけが実装の仕様として残る。

結論: 次の作業（設計・実装）は要らない。README と実装は一致しており、全角空白の扱いは仕様として記録するだけでよい。
