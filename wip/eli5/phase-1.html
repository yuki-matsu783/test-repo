フェーズ 1：テキスト整形ツールの説明を足した

いちばん大事なこと

ツールの動きは変えていません。main.sh の一番上に、使い方を書いたメモ（コメント）を 3 行足しただけです。

何をしたか

  • ツールの作り方が書かれた README と、main.sh の中身を見比べました。
  • ずれは見つからなかったので、直したところはありません。
  • メモを 3 行足しました。「どう使うか」「3 つの引数が何か」「絞り込みの言葉が空のときはどうなるか」を書いています。

変わったファイル

  • main.sh：上の 3 行のメモを足した（ほかの行は同じ）。

確かめたこと

  • 引数が足りないとき：使い方が表示されて、エラーで終わる。
  • 入力ファイルが無いとき：「見つかりません」と表示されて、エラーで終わる。
  • 言葉に合う行があるとき：番号が付いて、行の頭の空白が消えた形で、出力ファイルができる。
  • 言葉に合う行が無いとき：中身が空の出力ファイルができて、正常に終わる。

まだ確かめていないのは、「絞り込みの言葉を空にしたら全部の行が残る」という点です。コードを読んで、そうなると判断しました。

リスク

低いです。動くコードは変わらず、メモを足しただけなので、壊れる場所はほとんどありません。
