README に注意を 1 行足す

何のための変更か

README の「使い方」の表の下に、「引数は 3 つ必要です。」という 1 行を足します。使い方を読んだ人が、引数を 3 つ渡す必要があることに気づけるようにするためです。

何が変わるか

  • 変わるファイルは README.md の 1 つだけです。
  • 「使い方」の表と「仕様」の見出しの間に、空行と 1 行を足します（2 行の追加）。
  • 既存の文章は書き換えていません。

リスク

プログラムの動きは変わりません。文書の文言が増えるだけなので、リスクは低いと判定しています（LOW）。

確かめ方

  • README.md の差分が、「使い方」の表の直後への 1 行の追加（と空行）だけであること。
  • 追加された行が「仕様」の見出しより前にあること。
  • ほかのファイルに変更がないこと。
