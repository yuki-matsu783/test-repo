## 目的

README.md を読んだ人が、この文書が検証用の演習で、内容が予告なく変わることを最初に分かるようにする。

## 範囲

- README.md の見出し（`# 演習: テキスト整形CLI`）の直下に、注意書きを 1 段落足す
- 注意書きの案: 「> **注意**: この README は検証用の演習です。内容は予告なく変わることがあります。」
- 注意書きの文言は承認のときに変えてよい（子の作業は承認された文言に従う）

## 対象外

- README.md 以外のファイル（`main.sh` や他の文書を含む）
- 既存の本文・「テスト」の行・末尾の HTML コメント（`<!-- 78 検証用の下書き -->`）の書き換えと削除
- 仕様や完成の確認の項目の変更

## 完了の確かめ方

- README.md の 1 行目の見出しの直下に、注意書きの段落が 1 つ入っている
- `git diff` で変わったのが README.md の注意書きの行だけで、ほかの行は変わっていない（ccnavi-git.sh で確かめる）
- 注意書きの文言が、承認された文言と一致する

## 計画の理由

作業は 1 ファイルの 1 段落の追加で、範囲も親の範囲のまま。`quick-work` の 1 フェーズで十分。
