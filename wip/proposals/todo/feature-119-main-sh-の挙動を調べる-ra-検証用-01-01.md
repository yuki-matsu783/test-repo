`main.sh` の挙動を調べ、結果を `wip/research/summary.md` にまとめる。

調べる項目:

1. 引数が足りないとき（0 個・1 個・2 個）の終了コードと出力
2. 入力ファイルが無いときの終了コードと出力
3. 絞り込みパターンが空のとき（全行が残るか）と、`\` や `*` などを含むとき（文字どおりに扱われるか）
4. 一致する行が無いとき、出力ファイルが空で作られるか
5. 行頭の空白の除去と番号の振り方（先頭の空白・タブ・全角空白の扱い）
6. 出力ファイルが既にあるときの上書きの仕方
7. README の仕様（「完成の確認」の 3 項目）と実際の挙動が一致するか

手順:

- 確かめるための入力ファイルは `wip/research/` の中に作る。実行の出力も `wip/research/` の中に作る
- 各項目は、打ったコマンドと結果（終了コード・出力の要点）を `summary.md` に書く
- `main.sh` と `README.md` は変えない。範囲は `wip/research/*` だけ
- 結論の欄に、次の作業（設計・実装）が要るかどうかを 1 行で書く

完了の条件: `wip/research/summary.md` が 1 つ、上の 7 項目すべてに結果を持って存在する。
