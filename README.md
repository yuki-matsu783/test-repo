# 演習: テキスト整形CLI

入力ファイルから条件に合う行を絞り込み、整形して出力するコマンドを作ります。`main.sh` の `main` 関数の中身（TODO の箇所）を完成させてください。

## 使い方

```sh
sh main.sh <入力ファイル> <絞り込みパターン> <出力の接頭辞>
```

| 引数 | 内容 |
|---|---|
| 入力ファイル | 読み込むテキストファイル |
| 絞り込みパターン | この文字列を含む行だけを残す |
| 出力の接頭辞 | 出力ファイル名の先頭に付ける文字列 |

## 仕様

1. 入力ファイルを読む
2. 絞り込みパターンを含む行だけを残す
3. 残した行を整形し、`<出力の接頭辞>.txt` に書き出す

整形の中身（行頭の空白を除く、番号を振る、など）は自由に決めてください。

## 完成の確認

- 引数が足りないときは使い方を表示して終了する
- 入力ファイルが無いときはエラーで終了する
- 一致する行が無いときも、空の出力ファイルを作って正常終了する
